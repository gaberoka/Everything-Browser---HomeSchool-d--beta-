1) Install Ollama first. If not, you may be prompted to or the browser will not work. 

[Versions 2.6 and 2.7 will allow you to EASILY download Ollama AI models with a copy pasted link, from here, where you can browse all current AI models: ollama.com/search ]

Some versions lost the ability to download the AI models directly from the browser.

2) To download:

Click "Releases" to the right and download all folders/files you like from the Google Drive link there, or here:  https://drive.google.com/drive/folders/166nDsGZeWOvj5TtTexmfA1JRRjc9WpEV?usp=sharing

.jpgs included here for previews.


3) To run:

Open the folder and click the .exe labeled Homeschool'd or Homeschool'd Browser. At that time the file should run. If there are any errors, troubleshoot as needed.
